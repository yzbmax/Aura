## 1.1 泰勒主义的数字异化：从打卡钟到日历格

工业革命以来，弗雷德里克·温斯洛·泰勒（Frederick Winslow Taylor）的科学管理理论确立了人类对“分秒精度”、“吞吐率”和“流水线作业”的崇拜。在过去半个世纪中，这种基于机械生产线而非生物体的人类剥削逻辑，被原封不动地移植进了个人电脑与智能手机：
- **静态机械日历**将鲜活生命切片为 15/30/60 分钟的等长矩形方块，假定人类大脑与蒸汽机无异，能够在早晨 9:00 至下午 18:00 持续输出恒定的认知马力；
- **待办事项列表（To-Do List）**将复杂的认知意图退化为二维的行项目罗列，引发认知负荷爆炸（Working Memory Saturation）；
- **操作仪轨的荒谬性**：现代生产力软件要求疲惫不堪的用户执行“解锁手机 → 寻找图标 → 点击打开 → 在充满刺激的列表里定位 → 设定时间参数 → 点击开始”。这种交互本身就需要消耗极高阶的前额叶执行控制力（Executive Control）。**在人类认知能量最为匮乏、最需要支持的时刻，软件反而设置了最为严苛的认知摩擦壁垒。**
